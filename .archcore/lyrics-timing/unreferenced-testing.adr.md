## Context
6 сентября 2026 пользователь решил продолжить испытания без внешних эталонов: подготовка размеченного корпуса сейчас недоступна. @docs/word-timing-implementation-report.md фиксирует первый этап; @docs/timing-stability-report.md описывает реальные прогоны и контрольный кандидат `output/timing-candidate-v1`; @src/karaoke_generator/evaluation.py требует независимую разметку для метрик точности.

## Decision
Продолжаем локальные испытания реальных моделей, проверку инвариантов и устойчивости к известным преобразованиям аудио, а понравившийся пользователю результат сохраняем как контрольный вариант для регрессий.

После самостоятельной проверки пользователь оценил текущий результат как улучшившийся и в целом приемлемый. По его решению фиксируем реализацию как есть и описываем оставшиеся проблемы; дальнейшая настройка не входит в эту фиксацию. Конкретный видео/JSON-файл эталоном пока не назначен.

## Alternatives Considered
1. Размеченный корпус из ТЗ v1 отложили, поскольку пользователь сообщил о невозможности подготовить его сейчас.
2. Готовые караоке как внешние эталоны отложили, поскольку пользователь решил продолжить без их сбора и проверки.
3. Автоматически объявлять текущий результат истинными акустическими границами исключили, поскольку сравнение результата с самим собой не измеряет точность.

## Consequences
### Положительные
- [observed] Реальные прогоны выявили пропуск feature extractor, ошибочный отказ из-за округления границ и перенос короткого слова между блоками текста. Исправления проверены тестами и повторными прогонами.
- [expected] Известный временной сдвиг и повторение аудиофрагмента позволяют проверить сохранение временной шкалы и принадлежность слов.
- [expected] Зафиксированный контрольный вариант позволяет обнаруживать изменения вывода после доработок.

### Ограничения
- По отзыву пользователя при обработке песни с музыкой часть слов «съедается»; точный этап возникновения потерь пока не установлен.
- Некоторые слова подсвечиваются немного раньше или позже вокала. Эти локальные несовпадения остаются открытой проблемой.
- Абсолютные median/P90 акустической ошибки остаются неизмеренными без размеченных границ.
- Доля уточнений, score и устойчивость не доказывают совпадение с началом и концом основного вокала.
- До оценки пользователем сохранённый вариант имеет статус кандидата, а не выбранного эталона.

## Superseded when
- Пользователь предоставляет разметку хотя бы одного фрагмента для внешней проверки границ.
- Пользователь выбирает конкретный видео/JSON-вариант для фиксации в контрольном наборе.
